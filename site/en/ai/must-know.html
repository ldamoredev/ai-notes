Must Know

The minimum useful AI vocabulary is not a list of tools. It is a set of distinctions that prevent fuzzy thinking.

Baseline Distinctions

  • A model is not the product; it is one component in a system.
  • A prompt is an interface, not a substitute for product design.
  • Evaluation is not a final gate; it is an operating loop.
  • Retrieval improves grounding only when the index, ranking, and citation path are designed.
  • Safety and security are design constraints, not cleanup tasks.
