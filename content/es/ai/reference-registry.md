# Registro de Referencia

Este registro es un placeholder para referencias externas estables. Mantené citas y notas de fuente acá, y después enlazá las notas atómicas con la entrada relevante.

## Forma del registro

| Tipo | Entrada | Por qué importa |
| --- | --- | --- |
| Paper | Attention Is All You Need | Línea base de arquitectura transformer. |
| Dataset | Eval set interno | Checks de regresión para comportamiento de producto. |
| Herramienta | Índice vectorial | Experimentos de retrieval y grounding. |

## Política

No conviertas los registros en ensayos. Tienen que seguir compactos, normalizados y fáciles de escanear.
