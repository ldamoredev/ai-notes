# Must Know

El vocabulario mínimo útil de IA no es una lista de herramientas. Es un conjunto de distinciones para no pensar en niebla.

## Distinciones base

- Un modelo no es el producto; es un componente dentro de un sistema.
- Un prompt es una interfaz, no un reemplazo del diseño de producto.
- La evaluación no es una compuerta final; es un loop operativo.
- Retrieval mejora el grounding solo si diseñás índice, ranking y ruta de cita.
- Seguridad y safety son restricciones de diseño, no tareas de limpieza.
