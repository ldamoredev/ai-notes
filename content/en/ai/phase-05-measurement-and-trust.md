# Phase 05 — Measurement and Trust

Capability is not trust. Trust comes from evidence that matches the product, calibrated uncertainty, known failure modes, security boundaries, interpretable investigations, accountable ownership, and a release process that can stop or roll back.

## Mental model

Trust is a maintained evidence state, not a model property. Measurement, interpretation, security, and governance answer different questions and must converge on explicit release and rollback decisions.
