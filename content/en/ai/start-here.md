# Start Here

AI Atlas is a personal working map, not a complete textbook. Start by building vocabulary, then connect concepts to repeatable engineering practice.

## How to Use This Atlas

1. Read the phase pages in order.
2. Skim branch indexes before diving into individual notes.
3. Use playbooks when a concept needs to become a procedure.
4. Keep references in registries so atomic notes stay compact.

Start with [[ai/must-know|Must Know]], then read [[ai/foundations/mental-models-for-ai|Mental Models for AI Systems]] and [[ai/llms/transformer-attention-map|Transformer Attention Map]].
